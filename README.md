# Field Watch

現場の売上と請求をひとつにまとめるスマホ向けアプリです。
メールアドレスとパスワードでログインすると、役割に応じて次の画面が開きます。

| 画面 | 使う人 | できること |
|------|--------|------------|
| 総合管理画面 | 管理者（最初に作ったアカウント） | 全員分の次回入金予定、売上入力、請求書作成、仲間の入力の承認、仲間のアカウント管理 |
| 管理画面 | 一緒に働く仲間 | 自分の次回入金予定、売上入力、請求書作成（自分の名前で発行） |

- ログアウトボタンはありません。一度ログインした端末では、開くたびにログインが延長されます（1年）。
- 仲間が入れた売上は「承認待ち」として、承認前から合計に入ります。承認済み・承認待ちの件数と金額は分けて表示します。

## 次回入金予定の計算

売上ごとに請求先の「締め日」と「入金日」（例: 月末締め・翌月末入金）を持ちます。

1. 作業日から、その売上が含まれる締め日を出す（作業日以降で最初の締め日。31 = 月末）
2. 締め日から入金日を出す（当月／翌月／翌々月の◯日）
3. 未入金の売上を締め日のルールごとに分け、それぞれ一番早い入金日の分を合計（税込）

請求書作成で「入金済みにする」を押すと、次回入金予定から外れます。
請求先は一度入力すると保存され、次からボタンを押すだけで名前・締め日・入金日が入ります。

## 請求書作成

- 締め日別：締め日（5日・10日・15日・20日・25日・月末）を好きなだけ選んで合算
- 請求先別：請求先ごとの合計と明細
- 全体：その月に締まる請求すべての合計と、締め日ごと・請求先ごとの小計
- 出力：LINEにそのまま貼れる文章／Claudeに送る請求書作成プロンプト
- 請求書に載せる名前・振込先などは「発行者情報」から各自で設定

## 独立ページ（ログイン不要）

| URL | 内容 |
|-----|------|
| `/report` | ツールボックス。現場で使うツールの入口（新しいツールは `app/report/page.tsx` の TOOLS に追加） |
| `/report/sites` | 防草シート管理。施工リストの検索・地図・進捗管理・LINE用の進捗報告。進捗は `/api/sync` で全端末と同期 |
| `/report/ba`（`/ba` も同じ） | ビフォーアフター。① 看板が必要か（必要なら工事名・場所・色・開始番号）→ ② 枚数 → 撮影開始。左ビフォー／右アフター。撮影はスマホ標準のカメラ（縦向きのままでOK、真ん中を横長5:4で切り出し）、アルバムからは1枚ずつ。写真は端末内に保存 |

## 開発

```bash
npm install
npm run dev      # http://localhost:3000（画面のみ。APIは Cloudflare Worker 側）
npm run build    # 静的書き出し → out/
```

技術構成: Next.js 14（App Router / static export）/ TypeScript / Tailwind CSS /
Cloudflare Workers + D1（`worker/`）

- `worker/fieldwatch.js` … `/api/fw/*`（ログイン・仲間・請求先・売上・承認・入金・発行者情報）
- `lib/fw/billing.ts` … 締め日・入金日・次回入金予定・請求のまとめの計算
- `lib/fw/invoiceText.ts` … LINE用の文章と Claude 用プロンプト

## デプロイ

`npm run build` で `out/` を作り、`npx wrangler deploy` で `wrangler.toml` の設定どおり
静的ファイルと API を公開します。D1 のテーブル（`ts_users` / `fw_clients` / `fw_sales` /
`fw_profiles`）は初回アクセス時に自動で作られます。

ログイン情報を署名する秘密鍵を Cloudflare の Secret に設定してください
（未設定でも動きますが、本番では必ず専用の値にしてください）。

```bash
npx wrangler secret put TIMESHEET_SESSION_SECRET
# 長いランダム文字列を入力（例: openssl rand -hex 32 で生成）
```

### はじめての利用

1. サイトを開くと、最初の1回だけ管理者アカウントの作成画面が出ます（すでにアカウントがあればログイン画面）
2. 総合管理画面の「仲間」から、仲間の名前・メールアドレス・パスワードを登録して本人に伝えます
3. スマホではブラウザの「ホーム画面に追加」でアプリのように使えます
